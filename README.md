# PIKTO-IPS --- SITEEk

**Petualangan Literasi dan Numerasi IPS untuk Sekolah Dasar**

PIKTO-IPS merupakan media pembelajaran interaktif untuk membantu peserta
didik Sekolah Dasar belajar IPS melalui literasi, numerasi, piktogram,
data visual, konteks lingkungan sekitar, tantangan berjenjang, dan umpan
balik interaktif.

> **Baca Informasinya • Olah Datanya • Pahami Masyarakatnya**

## Tentang PIKTO-IPS

PIKTO-IPS mengajak murid tidak hanya membaca teks, tetapi juga membaca
data dan memahami kehidupan masyarakat.

**Konteks IPS → Literasi → Visualisasi Data → Numerasi → Penalaran →
Pengambilan Keputusan → Asesmen → Umpan Balik → Progres**

Materi menggunakan konteks yang dekat dengan kehidupan murid, seperti
Desa Ranuklindungan, Danau Ranu, serta kegiatan ekonomi di Pasar
Brandong, Desa Dawe. Data latihan yang bukan data resmi diberi
keterangan sebagai **data simulasi pembelajaran**.

## Alur Penggunaan

Saat aplikasi dibuka, video pembuka **`awal.mp4`** ditampilkan terlebih
dahulu.

Untuk pengguna yang sudah pernah masuk atau sudah tercatat, aplikasi
menunggu video pembuka selesai diputar **100%** sebelum melanjutkan ke
aplikasi.

Untuk pengguna baru, setelah video selesai, frame video mengecil ke
sebelah kiri formulir identitas. Murid mengisi **Nama Lengkap** dan
**Kelas**, lalu memilih **Masuk ke Aplikasi**.

Setelah berhasil masuk, video pembuka disembunyikan.

## Integrasi Data

Google Apps Script digunakan sebagai penghubung halaman web dengan
Google Spreadsheet. Sistem menangani data identitas pengguna, progres,
jawaban, hasil asesmen, refleksi, leaderboard, dan aktivitas
pembelajaran.

> **Catatan pengembangan:** jangan mengubah endpoint Apps Script,
> struktur sheet, atau nama field tanpa menyesuaikan frontend dan
> backend yang terkait.
